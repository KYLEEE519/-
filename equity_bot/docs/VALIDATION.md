## 关键测试覆盖

| 验收项 | 测试结果 |
|---|---|
| 市值严格>50亿、成交额严格>1000万、周振幅严格>5% | 边界等于门槛时拒绝；NaN/缺失拒绝 |
| 5日振幅不是涨跌幅，真实成交金额优先 | 与独立算式对比通过 |
| 正拆/反拆/10合1 | 调整后振幅、成交额和ATR不产生虚假跳动 |
| 无统一PE上限 | 盈利1e9/2e8/1e6/亏损均不会单因PE被硬筛掉 |
| 60日指标不成为额外硬门槛 | 20个完整交易日可通过，60日参考项为null |
| ADR及VIST非白名单 | 有核验证据可参与排序；市值不合格照常淘汰 |
| 50→10、同公司去重、行业最多2只、未知行业 | 全流程及不足数量通过 |
| 关键数据过期、未来披露、未来行情、严重风险 | 拒绝或排除未来数据，无历史泄漏 |
| 新闻转载、旧背景、标题不足、查询参数文章ID | 去重和背景标注通过，保留不同文章身份 |
| 新闻抓取缺失 | 不显示“没有负面新闻” |
| 三维研究、估值缺失、事件C与D | 不虚构场景/预测，不把C/D标为错杀合格 |
| 摘要字数 | 市场和个股均采用更严格100字规则，完整句模板压缩 |
| 邮件默认预览、模拟禁发、重复发送、重试、不确定状态 | 使用SMTP mock验证，未真实发送 |
| 日历 | 夏令时、独立日休市、感恩节后提前收盘通过 |
| 模型防越权 | 只能选择受约束摘要，无法改市值、名单或规则 |
| 前向审计 | 完整5/10/15交易日、相对收益、未到期缺失标记通过 |
| 新增/保留/重新入选、反馈 | 状态转换通过；反馈不能更改硬规则 |
| HTML外部内容 | 转义及CSP验证通过 |
